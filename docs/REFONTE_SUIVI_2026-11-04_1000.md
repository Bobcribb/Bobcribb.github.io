## Modification effective : chemin de lecture dans les corpus

Le module commun `scripts/apply_museum_design.py` insère maintenant après la bannière muséale, sur les pages rendues des études universitaires numérotées ou indépendantes, un **fil d'Ariane sémantique** `Accueil › Collection › Titre de l'étude`. L'élément HTML `nav.mythos-breadcrumbs` porte `aria-label="Fil d’Ariane"`, une liste ordonnée et `aria-current="page"` sur le titre courant.

Les destinations sont normalisées depuis les chemins existants, sans conversion de cote :
- `origines-du-sacre` → `/origines-du-sacre/` ;
- `encyclopedie` et `grece` → entrée grecque unique `/mythologie-grecque/` ;
- `comedies` et `tragedies` → `/theatre/` ;
- `comparatif` → `/mythologie-comparee/` ;
- `philosophie` → `/philosophie/`.

Ces liens complètent les sommaires scientifiques déjà publiés et facilitent le retour depuis une monographie longue vers son catalogue. Les paragraphes de recherche, références, sources primaires, bibliographies, ancres, liens canoniques et numéros ne sont pas réécrits. La transformation retire une éventuelle ancienne version du fil d'Ariane avant régénération, afin de rester **idempotente**. L'accueil ne reçoit pas ce composant réservé aux lecteurs.

Le style est défini dans `assets/mythos-museum.css` : contraste ivoire/or, filet fin, liens soulignés, césure des titres longs, flexbox adaptative, largeur réduite sur téléphone ; le fil est masqué à l'impression. La bannière image statue à gauche / temple à droite, les cartes illustrées et les galeries photoréalistes sont conservées. Aucune ancienne illustration 2,5D n'a été réintroduite.
